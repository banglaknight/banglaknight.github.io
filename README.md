# BanglaKnight: BLP-2027 Shared Task 1

Website for **BanglaKnight**, Shared Task 1 (Adversarial Prompt Classification) at the
[Third Workshop on Bangla Language Processing (BLP 2027)](https://blp-workshop.github.io/), co-located with NAACL 2027.

Live site: https://banglaknight.github.io/

## Files

```
index.html              all page content
assets/css/style.css    styles (colors are CSS variables at the top; dark mode included)
assets/js/app.js        demo tabs, mobile menu, active nav link
assets/img/logo.svg     logo and favicon
```

Plain HTML, CSS and JavaScript. Nothing to build or install.

## Preview locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Publishing

GitHub Pages serves the `main` branch root. The site updates a minute or two after each push.

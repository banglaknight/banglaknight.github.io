What you get

Each example is one Bangla prompt and its label (0–3). All three written forms of a prompt are in the same split, so a model never sees one form in training and another in testing.

Three written forms

Every prompt appears three times, once in each form, always with the same label:

  • Bangla script: written in Bangla letters.
  • Romanized: Bangla typed in Latin letters.
  • Code-mixed: Bangla mixed with English, Hindi, or Urdu.

A good system gives the same label to all three. Click the tabs in the example to switch forms.

BanglaKnight

Adversarial prompt classification for Bangla

Given a Bangla prompt, predict how risky it is: Safe, Offensive, Harmful, or Severe. Each prompt is written in Bangla script, in romanized Bangla, or code-mixed with another language, and your system should give the same answer for all three.

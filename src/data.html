{{i:type}}Three written forms

Every prompt appears three times, once in each form, always with the same label:

  • Bangla script: written in Bangla letters.
  • Romanized: Bangla typed in Latin letters.
  • Code-mixed: Bangla mixed with English, Hindi, or Urdu.

A good system gives the same label to all three, so a harmful prompt cannot slip through by switching scripts. Click the tabs in the example to switch forms.

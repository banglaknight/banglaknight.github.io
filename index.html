BanglaKnight

Adversarial prompt classification for Bangla

Given a Bangla prompt, predict how risky it is: Safe, Offensive, Harmful, or Severe. Each prompt is written in Bangla script, in romanized Bangla, or code-mixed with another language, and your system should give the same answer for all three.

The task

Label each Bangla prompt with one of four risk levels

Input

One Bangla prompt, written in Bangla script, romanized Bangla, or code-mixed text.

→
Output

One label: 0 Safe, 1 Offensive, 2 Harmful, or 3 Severe.

Background

Before an LLM answers a request, a safety classifier often checks whether the request is safe to answer. Most of these classifiers are trained on English. Bangla is often typed in Latin letters or mixed with English, Hindi, or Urdu, and a harmful request can get past a filter when it is spelled differently.

The four labels

0

Safe

No harmful request.

Neutral, positive, or harmless requests

1

Offensive

Insulting, provocative, or discriminatory language, but no request for harmful help.

Offensive language, hate speech, anger

2

Harmful

Asks for help with something of lower or medium risk.

Misinformation, adversarial and malicious requests

3

Severe

Asks for help with something high-risk that could cause serious harm.

Suicide, jailbreak attempts

Every prompt comes in three written forms with the same label. See Data for an example.
